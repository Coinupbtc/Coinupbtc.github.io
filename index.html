Selected public work

Repos, with the number that justifies them.

  • miaai35-tune Serving-profile tuning for a 35B model on one Spark — the bench harness, the rejected experiments, and the arithmetic behind each. 169.4 t/s coding
  • zwell-bench Head-to-head harness for local models. Fixed token budgets, fixed prompts, and a hard rule that a score without its budget is not a measurement. 4 tasks · 1 budget
