Selected work

Personal projects, running in production at home. Open a row for the full story.

  • Dual-node local AI cluster

    Self-hosted language models and always-on agents on two NVIDIA DGX Spark machines.

    AI infrastructure · 2026

    Problem

    Always-on AI agents with full data privacy and zero per-token cost — which ruled out cloud APIs entirely.

    Build

    Two DGX Spark nodes on a 200-gig fabric running llama.cpp inference servers; agent gateways with cron scheduling, Telegram delivery, failure-paging watchdogs, and nightly off-site backups. Tuned with speculative decoding, quantization A/Bs, and engine rebuilds — every change gated by a 19-check quality benchmark.

    Proven

    • 36 → 169 tokens/sec (4.7×) on a 35B model
    • NVFP4 quantization benchmarked to parity with Q8, then adopted — freeing 24GB of RAM
    • 19/19 on a machine-graded eval harness built from my own real workload
    • 1M-context model served tensor-parallel across both nodes over the 200-gig fabric

  • Bitcoin Blockfield

    The Bitcoin mempool as a watchable, live arena.

    Creative systems · 2026

    Problem

    Mempool data is rich but unreadable. The next block is a real contest — it deserved to look like one.

    Build

    Projected block contenders rendered as fighters, live fee-band routing as transactions shift, and an inscription radar that decodes images straight out of raw witness data.

    Proven

    • Runs live against public Bitcoin APIs
    • Smoke-tested on desktop and 500px mobile

    View the code on GitHub →

  • Trading-card arbitrage scanner

    Automated price-gap hunting across card markets, delivered to my phone.

    Automation · 2026

    Problem

    Real spreads exist between card marketplaces, but finding them by hand doesn’t scale past a hobby.

    Build

    Scheduled scans with embedding-based card-identity matching, a price cache and match ledger, strict verifier gates before anything is called a hit, and a top-10 digest pushed to my phone — iOS companion viewer included.

    Proven

    • Runs every 3 hours, unattended
    • Failures page me — silent breakage isn’t allowed

  • Prompt-to-3D-print sandbox

    Plain English in, printable STL/STEP out.

    Tooling · 2026

    Problem

    Going from “I need a bracket” to a printable file usually means CAD skills and an afternoon.

    Build

    A web app where a language model writes parametric CAD code behind an AST safety guard, with an automatic retry loop, printer bed-fit checks, and slicer recommendations.

    Proven

    • End-to-end: prompt → model → sliced → printed part
    • Survives bad generations — the retry loop earns its keep
