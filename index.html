Flagship

miaai35-tune

Flag-by-flag llama.cpp bakeoff for Qwen3.6-35B-A3B on DGX Spark. The clean-restart baseline is 35.80 tok/s coding decode (thinking off, speculative decode off, quality 9/10) from the committed JSON. Flash attention, KV quantization, context size and slot flags each moved it less than 2%. Turning thinking off cut wall-clock from up to 98 s to under 15 s. Numbers with no saved file are named and not quoted.

90 sMonday path

helix-qms-desk

ISO 13485 quality desk for a fictional biomedical plant. Walk Monday in 90 seconds: calibration sticker ≠ certificate, CAPA 8D, supplier SCARs, an ISO 14971 residual that got worse after a “control”. Then run IQ/OQ/PQ against the desk and a local assist model, where HTTP 200 with empty content counts as a failure. All records synthetic.

read-onlylocalhost

spark-console

One local pane for DGX Spark GPU, memory, model inventory and endpoint health, with an optional second node over SSH. Binds 127.0.0.1, rejects foreign Host headers (DNS rebinding) and foreign Origin writes. No start, stop or kill routes. Nothing phones home.

121 GBper Spark

spark-pack

Pack models onto 1–3 DGX Sparks before you start them: FITS, TIGHT, or won’t start. 121 GB is per Spark, not a pooled cluster, which is the mistake that hard-reboots a box. Catalog sizes are measured and dated; the live probe only reads, never starts anything.

55.5 sRoCE, was 90.5 s

MiniMax-H3-2x-DGX-Spark

A fork of Joey Rodriguez’s two-Spark MiniMax H3 recipe; the recipe is his. My part: GB10 CX7 RoCE bring-up so the two nodes talk over InfiniBand instead of TCP (GID index 3, matched MTU, unlimited memlock). Same seed-42 clip: 90.5 s over TCP, 55.5 s over RoCE (repeat 58.4 s), output identical. Code is Apache-2.0. MiniMax H3 weights and outputs fall under MiniMax’s own Community License, which has territory limits. The repo ships no weights and no media.

STL + STEPlocal

stl-sandbox

Plain-English prompt to printable STL and STEP, fully local (CadQuery plus an optional local LLM). Checks bed fit and mesh health before you slice, and writes an ISO 2768-style inspection report per part. Honest boundary: prototype geometry control, not AS9100 or flight qualification.

14/15published

zwell-bench

15-check gate for local LLMs: executed coding tests, web extraction, vision reads, tool choice, agentic ordering. The gate aims for all-green; the published baseline (16 July 2026) is 14/15, weighted 95.0, one agentic miss (schedule_math). None of the four committed runs is 15/15, and the README says so.
